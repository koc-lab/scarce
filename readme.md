# scARCE: Graph Enhanced Transformer Encoder for Single-Cell Annotation

This repository contains the source code for our paper "scARCE: Graph Enhanced Transformer Encoder for Single-Cell Annotation", which is currently under review at *IEEE Transactions on Signal and Information Processing over Networks*.

The code for reproducing the main results of the paper is available at https://github.com/kocemir/scarce.

Detailed results for all datasets, ablation studies, and figures will be released in this repository soon.
